Автомобили / Детейлинг — 2026

VELAR DETAIL

Премиальный сайт детейлинг-студии: услуги, цены, галерея работ, блок Before / After и форма записи.

Открыть сайт ↗

01

Проект

Одностраничный сайт детейлинг-студии. Задача — показать уровень услуг и довести посетителя до записи. Тёмная «автомобильная» подача, тёплый золотой акцент, крупная типографика.

02

Задача

Детейлинг продают результатом, а результат трудно объяснить текстом. Нужно было построить страницу так, чтобы посетитель сначала увидел разницу «до / после», а потом дошёл до формы записи.

03

Подход

Чёткая последовательность экранов: услуги → цены → работы → запись. Каждый блок заканчивается понятным следующим шагом. Тёмная палитра держит внимание на фотографиях автомобилей.

04

Возможности

  • Интерактивный слайдер Before / After
  • Блок услуг и прозрачный прайс
  • Форма записи с валидацией
  • Мобильное меню и адаптив от 320px

05

Технологии

  • HTML5
  • CSS3
  • JavaScript
  • CSS Grid
  • Flexbox
  • GitHub Pages

06

Результат

Готовый сайт опубликован на GitHub Pages и доступен по прямой ссылке. Открывается на десктопе и мобильном, все интерактивные элементы работают без сторонних библиотек.

Ресторан / Гостеприимство — 2026

SHAFRAN

Современный сайт ресторана с акцентом на атмосферу, меню, фотографии и бронирование.

Открыть сайт ↗

01

Проект

Сайт ресторана восточной кухни. Полноэкранная фотография, тёплая тёмная палитра, разделы «О ресторане», «Меню», «Галерея», «Бронирование» и «Контакты».

02

Задача

У сайта ресторана два разных посетителя: один хочет понять, что это за место, второй — быстро забронировать столик. Нужно было решить обе задачи, не потеряв атмосферу.

03

Подход

Атмосферу держат крупные фотографии и спокойная типографика, а действие — кнопка бронирования, доступная из шапки на любом экране. Меню разбито по категориям, чтобы его было удобно листать с телефона.

04

Возможности

  • Меню с категориями и фотографиями блюд
  • Галерея интерьера и подачи
  • Форма бронирования с валидацией
  • Липкая навигация и мобильное меню

05

Технологии

  • HTML5
  • CSS3
  • JavaScript
  • WebP + srcset
  • Локальные variable-шрифты
  • GitHub Pages

06

Результат

Сайт опубликован на GitHub Pages. Изображения отдаются в WebP в нескольких размерах, шрифты подключены локально подмножествами latin + cyrillic — страница остаётся лёгкой даже при большом количестве фотографий.

Архитектура / Бюро — 2026

ATLAS ARCHITECTS

Премиальный сайт архитектурного бюро, разработанный мной с нуля.

Открыть сайт ↗ Смотреть код ↗

01

Проект

Сайт архитектурного бюро — лонгрид с разделами о бюро, проектами, услугами, процессом и командой. Двуязычный интерфейс RU / EN, монохромная палитра, строгая сетка.

02

Задача

Архитектуру продаёт изображение, а не текст. Интерфейс не должен спорить с фотографиями — но при этом обязан удерживать структуру длинной страницы и работать на двух языках.

03

Подход

Редакционная сетка, много воздуха, сдержанная анимация. Центральная идея — слайдер «Чертёж → Постройка»: посетитель сам переводит проект из чертежа в готовое здание.

04

Возможности

  • Двуязычный интерфейс RU / EN
  • Слайдер «Чертёж → Постройка»
  • Анимированная статистика
  • FAQ-аккордеон с корректной клавиатурной работой
Полный список технических особенностей
  • Адаптивная вёрстка и мобильная навигация
  • Плавная прокрутка и навигация с клавиатуры
  • Поддержка prefers-reduced-motion
  • Accessibility: aria-атрибуты, состояния фокуса, контраст
  • SEO: мета-теги, Open Graph, Schema.org
  • sitemap.xml и robots.txt
  • Оптимизация изображений под разные экраны

05

Технологии

  • HTML5
  • CSS3
  • JavaScript
  • i18n (RU / EN)
  • Schema.org
  • Open Graph
  • Netlify
  • GitHub

06

Результат

Сайт опубликован, исходный код открыт на GitHub. Самый редакционный и самый технически насыщенный из трёх проектов: двуязычность, интерактивный слайдер и полный набор SEO- и accessibility-настроек.
