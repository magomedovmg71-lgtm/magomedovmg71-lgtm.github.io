# MAGOMEDOV.WEB — основной сайт

Личный сайт веб-разработчика из Махачкалы: услуги, портфолио, форма заявки.
Двуязычный, RU/EN. Живёт на **magomedov.website**.

**Стек:** HTML5 / CSS3 / JavaScript без фреймворков. Плюс Cloudflare Worker
для приёма заявок.

## Куда смотреть

| Нужно | Файл |
|---|---|
| Разметка всех секций, русские тексты | `index.html` (963 строки) |
| Стили | `css/style.css` |
| Логика страницы, отправка формы | `js/script.js` |
| Английский перевод и строки для JS | `js/i18n.js` |
| Приём заявок, отправка в Telegram | `worker/index.js` |
| Настройка воркера | `worker/wrangler.toml` |
| Домен для GitHub Pages | `CNAME` |
| Карта сайта, индексация | `sitemap.xml`, `robots.txt` |
| Картинки, шрифты | `images/`, `fonts/` |

Русский текст лежит прямо в `index.html` — страница читается без JS.
Английский подставляется из `i18n.js` по атрибутам `data-i18n`,
`data-i18n-aria`, `data-i18n-alt`.

## Точка входа

`index.html` — сайт одностраничный.

## Деплой

GitHub Pages, репозиторий `magomedovmg71-lgtm/magomedovmg71-lgtm.github.io`,
ветка `main` → **magomedov.website** (домен задан в `CNAME`).

Выкатка: коммит → `git push origin main`. Через 1–2 минуты на сайте,
у клиента может кэшироваться — обновлять Ctrl+F5.

Воркер выкатывается отдельно из папки `worker/` командой `wrangler deploy`.

## Что важно помнить

- **Секреты воркера в коде не лежат.** Токен бота, chat id и ключ почты
  задаются через `wrangler secret put ИМЯ` и хранятся на стороне Cloudflare.
  Не вписывать их в файлы и не коммитить.
- Воркер отвечает только своим доменам (список `ALLOWED_ORIGINS` в
  `worker/index.js`). Меняешь адрес сайта — добавь его туда, иначе форма
  перестанет принимать заявки.
- На этом же домене лежат проекты-подпапки: `/naruki/`, `/shafran/`,
  `/velar-detail/`, `/atlas-architects/`. Они деплоятся **из своих репозиториев**, не отсюда.
  В `sitemap.xml` они перечислены — добавил проект, впиши его туда.
- В корне лежат файлы подтверждения прав для Google и Яндекса
  (`googleb42...html`, `yandex_f22...html`) — не удалять, слетит верификация.
